# -AI-Powered-Resume-Analyzer-and-Job-Matching-System
My project is an AI-Powered Resume Analyzer and Job Matching System developed using Python, NLP, Scikit-learn, spaCy, and PyMuPDF. It extracts text from PDF resumes, compares resumes with job descriptions using TF-IDF and Cosine Similarity, calculates a matching score, and identifies missing skills to help candidates improve their resumes.
